Scene-CLIP: Enhancing Compositional Scene Understanding With Scene Graphs
Large-scale vision-language models (VLMs) like CLIP excel in general image-text alignment but struggle with fine-grained compositional understanding, failing to correctly ground object attributes, relationships, and spatial configurations. Previous works incorporating scene graph knowledge (SGK) improve compositionality but rely on heavy external encoders or modifications to pretrained backbones, breaking end-to-end optimization in the vision-language embedding space. Recent works address this limitation through synthetic hard-negative sampling, improving compositional performance. Informed by this, we introduce Scene-CLIP, a lightweight, attention-based framework that enhances CLIP’s compositional reasoning through two key innovations: (1) a dual negative sampling strategy combining syntactic negatives (e.g., swapped object-relation pairs) with semantic hard negatives and (2) a parameter-efficient triple aggregator that processes scene graph triples directly within CLIP’s embedding space. Experiments show substantial improvements across multiple tasks, outperforming many state-of-the-art methods on SugarCrepe, SugarCrepe++, and Visual Genome benchmarks with an average 12% accuracy gain over CLIP and improving group retrieval scores on the VisMin benchmark by 16% relative to a fine-tuned CLIP baseline. Notably, Scene-CLIP surpasses strong recent baselines while using 28% fewer parameters than prior SGK-based approaches, illustrating that incorporating scene graphs with sophisticated negative sampling advances compositional reasoning in VLMs.
Defense in Depth: Intrusion Detection and Orchestrated Mitigation for Microservices
Microservice architectures are highly susceptible to distributed security threats due to their decentralized nature and inter-service communication overhead. This work introduces an integrated defense-in-depth framework combining real-time intrusion detection mechanisms with automated, orchestrated mitigation protocols. By analyzing runtime system telemetry and service call patterns, the proposed architecture rapidly isolates compromised containers and enforces granular policy restrictions without disrupting normal user traffic, minimizing cascading failures across cloud environments.
